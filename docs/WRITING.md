# 表記のきまり

このサイトの日本語の書き方。読み手は小学校3〜4年生くらい。
`web/server/text_rules.test.ts` が 1・2・5 を機械的にチェックする。

## 1. 漢字とルビ

- **小学校で習う漢字（学年別漢字配当表の 1,026 字）は漢字で書く。**
  それ以外の漢字はひらがな・カタカナで書く（鍵 → カギ、壊す → こわす、偽 →
  にせ、盗む → ぬすむ、桁 → けた、攻撃 → こうげき）。
- **漢字にはすべてルビがつく。** ルビは JSX
  ランタイム（`web/client/jsx_runtime.ts`） が `web/client/ruby/words.ts`
  の単語リストから自動でつける。漢字を書いたら、
  その単語を読みといっしょにリストへ足す。
- 例外（ほんとうの名前）:
  正式名称・専門用語は、配当表にない漢字でも漢字で書いてよい。
  ただし次の場所だけ。
  - 「やさしい言い方（ほんとうの名前）」の（）の中
  - `GrownUpNote`（大人向けメモ）と `Sources`（出典）の中
  - テストの `TERMS` に入っている語（例: 秘密鍵、公開鍵、耐タンパー性、搭載）

## 2. 漢字で書けても、ひらがなで書くもの

ことばの「はたらき」を表す語は、配当表の字でもひらがな。

| 種類                   | 書き方                                                                     |
| ---------------------- | -------------------------------------------------------------------------- |
| 形式名詞               | こと、もの、とき、ところ、ため、よう、ほう、わけ                           |
| 補助動詞               | 〜てみる、〜ていく、〜てくる、〜ておく、〜てしまう、〜てもらう、〜てあげる |
| よく使う動詞           | ある、いる、なる、する、できる、わかる、いう（「〜という」）               |
| 副詞・接続詞           | まず、もし、さらに、とても、いちばん、いっしょに、たくさん、ちょうど、また |
| 助詞・あとにつくことば | など、まで、ごと、くらい、だけ、ほど                                       |

それ以外の動詞・名詞は漢字（見る、作る、確かめる、本当、本物、問題、番号）。

## 3. ことばをそろえる

| 使う                   | 使わない                             |
| ---------------------- | ------------------------------------ |
| マイナンバーカード     | マイナカード、マイナ                 |
| カード（くり返すとき） |                                      |
| ICチップ、チップ       | IC チップ                            |
| ひみつのカギ（秘密鍵） | 鍵、かぎ、秘密のカギ                 |
| 公開のカギ（公開鍵）   |                                      |
| 電子署名、電子証明書   | 署名、証明書（ほかと区別が要るとき） |
| 暗証番号               | パスワード                           |
| 本物、にせもの         | 偽物、ニセモノ                       |
| 確かめる               | たしかめる、チェックする             |
| 本当                   | ほんとう                             |
| 第1章                  | だい1しょう                          |
| 大人向けメモ           | おとなの人向けメモ                   |

## 4. 文体

- 本文・図の説明は話しことば（〜だよ、〜するんだ、〜かな？）。
- 大人向けメモと出典は書きことば（〜する。〜である）。

## 5. 数字・記号・スペース

- 数は算用数字（半角）: 1回、3つ、4けた、2026年10月20日。 ことばの一部は漢字:
  一度も、一人ひとり。
- 半角の英数字と日本語のあいだにスペースを入れない:
  ICチップ、J-LISに聞く、4けた。
- 句読点・かっこは全角: 、。「」（）？！
