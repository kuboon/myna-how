# myna-how — サイト構成プラン

マイナンバーカードの仕組みを、**動く図**で、**小学生にもわかる言葉**で説明する
静的サイト。サーバーは使わない（GitHub Pages）。

## 方針

- **static モード**（`TEMPLATE.md` ステップ 0）。`/api/*`
  やサインインなどテンプレのデモ機能はすべて削除する。
- 1 ページ 1 テーマ。どのページも「たとえ話 → 動く図 → まとめ（ひとことで）」
  の順に並べる。
- 言葉: 漢字は少なめ、専門用語は「やさしい言い方（ほんとうの名前）」で出す。 例:
  「ひみつのカギ（秘密鍵）」「ハンコ（電子署名）」。
- 動く図は island（`@remix-run/component` の `clientEntry`）で作る。
  ボタンを押して 1 ステップずつ進む形にして、自分のペースで読めるようにする。
  JavaScript が無くても最初の図と文章は読める。
- 絵は全部インライン SVG / CSS（画像ファイルなし）。
- 事実は公式資料に合わせる（各ページ末尾に「もっとくわしく」として出典リンク）。

## ページ構成

| - | -------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |

| 1 | `/inside/`           | カードの中には何が入っている？             | IC チップをタップすると「部屋」が開く。4 つの部屋（署名用・利用者証明用・券面入力補助・券面）と「入っていないもの」 |
| 2 | `/tamper/`           | こわそうとすると、こわれる（耐タンパー性） | 「こじあける」「電気をいじる」「暗証番号を当てずっぽう」を試すとチップが身を守る。3 回まちがえるとロック            |
| 3 | `/phone/`            | スマホにマイナカードが入っているって？     | カード→スマホの登録アニメ。カギは「コピー」ではなく、スマホの金庫の中で新しく作る                                   |
| 4 | `/auth/`             | どうやって「本人」だとわかるの？           | サイトが出す「なぞの数字」にチップがハンコ → 見本と照らし合わせ → 有効か確認。にせものカードは失敗                  |

## 各章で伝えること（要点）

1. **中身**: チップに入っているのは「電子証明書（2 種類）」「券面の文字情報」
   「顔写真など券面の情報」。税金・病気・成績・お金などは**入っていない**。
   署名用は 6〜16 文字のパスワード、それ以外は 4 けたの暗証番号で守られている。
2. **耐タンパー性**:
   ひみつのカギはチップの外に**一度も出ない**。計算（ハンコ押し）
   はチップの中だけ。こじあけ・電気の細工を感じるとチップが中身を守る。暗証番号は
   まちがえすぎるとロック（利用者証明用 3 回、署名用 5 回）。
3. **スマホ**: スマホの中の「金庫」（セキュアエレメント）に、スマホ専用の
   電子証明書を**新しく**発行してもらう。カードのカギをコピーするのではない。
   iPhone は顔・指紋で暗証番号の代わりにできる。機種変更・紛失時は止められる。
   できることは「ネットで使う（電子証明書機能）」と「目の前の人に見せる
   （属性証明機能、対面確認アプリで読む）」の 2 つ。iPhone は 2025 年 6 月 24
   日から。Android は 2023 年 5 月からスマホ用電子証明書、2026 年 10 月 20
   日（予定）に「Android のマイナンバーカード」（Google ウォレット）へ刷新され、
   属性証明機能が加わる。
4. **認証**: チャレンジ・レスポンス。サイトが毎回ちがう数字を出す →
   チップがひみつのカギでハンコ → サイトは公開鍵（見本）で確かめる → J-LIS
   に「この証明書、まだ使える？」と聞く。毎回数字が変わるので、
   のぞき見て使い回してもダメ。
5. **匿名**: 利用者証明用の電子証明書には名前も住所も書いていない。
   デジタル認証アプリでは、お店ごとにちがう番号（ペアワイズの仮名
   ID）を渡すので、
   お店どうしで「同じ人だ」と結びつけられない。名前などは本人が「いいよ」と
   言ったときだけ渡る。
6. **デジタル認証アプリ**: デジタル庁が作ったアプリ。お店（サイト）は OpenID
   Connect という世界共通のログインの決まりで組み込める。 認証 API
   は無料。年齢確認・ネットのログインなどに使える。

## 実装メモ

- テンプレのデモ機能（サインイン・push・blog・API など）はすべて削除済み。
  `og/`（SNS カード）は残す。
- 新規: `web/client/pages/*.tsx`（各章）、`web/client/islands/*.tsx`
  （各章の動く図）、`web/client/chapters.ts`（章の一覧。ナビと目次が読む）。
- 配色は明るくやさしい色（`static/app.css` のトークンを変更）。
- `deno task check && deno task test && deno task build` と
  `deno task test:browser` を通す。
